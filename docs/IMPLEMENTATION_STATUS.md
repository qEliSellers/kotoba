## Remaining work and limits

1. **Audible audio and broader accessibility QA remain unfinished.** The browser exposes prompt and answer repeat controls and the kanji-reading prompt exposes no audio control, but this tool cannot listen to sound. Confirm Japanese voice playback, mute and offline behavior on the target Mac. Targeted keyboard/focus and 760px/1280px checks passed; a full screen-reader, cross-browser and comprehensive visual audit has not been performed.
2. **Conjugation semantic eligibility is conservative, not exhaustive.** The complete requested form catalog and representative classes are implemented. Eligibility includes a small stative/inherent-ability exclusion set and per-entry overrides. Unknown irregular classes are excluded. Unusual lexical exceptions and all contextual distinctions across an arbitrary imported dictionary require further curated fixtures. Standard する compounds are supported; do not assume every lexical する verb has regular potential/negative behavior.
3. **Scheduling remains an experimental heuristic.** It passes the specified calibration and integrity checks, but has not been fitted or validated against long-term learner data. There is no trained FSRS optimizer. Tuning constants live in one core module and are visible read-only in Settings; no graphical scheduler-tuning editor is implemented.
4. **Large-library performance is not benchmarked.** Library searches and candidate generation currently read structured entry data in process. The library table displays the first 1,000 filtered rows and explains that limit; bulk selection includes all filtered results. Statistics load stored attempts in memory. Before very large dictionaries/history collections, add server-side pagination, cached/indexed search fields, and bounded confusion-candidate retrieval.
5. **Idle/pause-aware timing is not implemented.** An unanswered item retains its first presentation time. Time spent leaving it open or returning to it later counts toward response seconds and speed penalties. Reverse self-grading correctly stops the clock at reveal.
6. **Evolution currently shows daily attempt/correct counts**, with exact underlying rows. It does not recreate the reference screenshot's stacked historical mastery-area chart. Current maturity categories use earned maturity to avoid rewarding rapid repeats. Current-card rankings/maturity are not historical as-of-date reconstructions.
7. **Import parser limits are explicit.** Valid CSV with invalid rows receives a row report. Structurally unparseable CSV (for example an unterminated quote) stops the preview with an error rather than attempting lossy recovery. Meanings use exact imported alternatives; romanization normalization is deterministic but not an exhaustive acceptance policy for every transcription convention.
8. **Optional named lists and a dedicated graphical card-type suspension manager are not implemented.** Filtering and activation work by entry, deck and direction; missing kanji reading types are shown with reasons. The specification's optional list system can be added using the existing IDs.
9. **No permanent history-deletion feature is exposed.** Entry deletion is soft and confirmed, preserving audit records. Restoring a complete backup replaces the workspace after confirmation and saves a recovery copy.

There are no fabricated review counts, placeholder quiz outcomes, randomly generated scheduling results, or network-generated conjugation answers. Sample CSV files are explicitly illustrative and are never automatically imported or activated.

## Browser QA notes and remaining checks

The browser test used a separate temporary database. It exercised the workflows listed above, including restoration of a versioned backup and a subsequent server restart. The review chart showed two correct points in green, one wrong point in red, and one pass in yellow for the same card; all four matching raw rows appeared below it. An early repeat showed a real streak increase without materially changing the due date. No browser console errors were reported during the checks.

The test revealed and led to fixes for answer-audio repeat after reveal, visible restore-success feedback, dialog focus and validation-message placement, resuming older unfinished sessions, readable conjugation labels in statistics, and an incorrect derived-rank label for an unranked kanji. The kanji editor now explains missing reading cards while editing.

Still to verify in a future pass: audible speech and local voice availability; multiple screen-reader/browser combinations; broader responsive and visual review beyond the sampled screens; and dedicated UI checks for the reserved conjugation slots 3 and 4. The underlying reservation logic is covered by automated service tests.
